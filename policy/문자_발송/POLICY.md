# 문자 발송 정책

## 적용 범위

이 문서는 동아리 운영을 위한 문자 발송의 권한, 수신자, 문자 메시지, 발송 유형 및 발신번호에 관한 판단을 정의한다.

## 정책

### 문자 발송 권한

- 문자 발송은 [운영진 정책](../운영진/POLICY.md)에 따른 운영진만 수행할 수 있다.
- 운영진은 동아리 운영에 필요한 목적으로만 문자 발송을 수행한다.
- 문자 발송 권한은 다른 회원에게 위임하거나 공유할 수 없다.

### 회원 수신자

- 회원을 수신자로 지정할 때에는 사이트에서 현재 회원으로 관리되고 있는 회원만 지정할 수 있다.
- 교류 회원은 회원 수신자 선택 대상에 포함하지 않는다.
- 회원에게 등록된 전화번호가 없는 경우 해당 회원에게 문자 발송을 수행하지 않는다.
- 회원 전화번호는 숫자 이외의 문자를 제거한 뒤 사용하며, 제거 결과가 비어 있으면 해당 회원에게 문자 발송을 수행하지 않는다.

### 직접 지정 수신자

- 회원이 아닌 수신자는 전화번호를 직접 지정하여 문자 발송할 수 있다.
- 직접 지정 전화번호는 쉼표로 구분하여 여러 개를 지정할 수 있다.
- 시스템은 직접 지정 전화번호에서 숫자 이외의 문자를 제거한 값을 수신 전화번호로 사용한다.
- 숫자 이외의 문자를 제거한 결과가 비어 있는 값에는 문자 발송을 수행하지 않는다.
- 동일한 회원 ID 또는 정규화된 전화번호가 여러 번 지정되면 첫 번째 지정만 발송하며, 회원 수신자와 직접 지정 수신자의 전화번호가 같으면 회원 수신자를 우선한다.

### 문자 메시지

- 문자 메시지의 내용은 공백만으로 이루어질 수 없다.
- 문자 메시지에 `{realname}`을 포함하면 회원 수신자에게는 해당 회원의 이름으로 치환하여 발송한다.
- 직접 지정 수신자에게는 `{realname}`을 숫자만 남긴 정규화된 수신 전화번호로 치환하여 발송한다.
- 문자 메시지는 발신 전용 안내가 필요한 경우 그 사실을 내용에 명시한다.

### SMS와 LMS의 자동 전환

- 문자 메시지의 바이트 수가 90바이트 이하이면 SMS로 발송한다.
- 문자 메시지의 바이트 수가 90바이트를 초과하면 LMS로 자동 전환하여 발송한다.
- 바이트 수는 ASCII 문자를 1바이트, 그 밖의 문자를 2바이트로 계산한다.
- 바이트 수는 수신자별 치환이 완료된 문자 메시지를 기준으로 계산한다.
- 회원별 이름 치환 결과에 따라 동일한 발송 요청에서도 수신자별 문자 메시지 유형이 달라질 수 있다.
- 운영진이 문자 메시지 유형을 수동으로 선택하여 자동 전환 규칙을 우회할 수 없다.
- LMS로 발송하는 경우 문자 메시지 제목은 `쿠러그, 경희대학교 중앙 IT 동아리`로 한다.

### 발신번호

- 문자 발송에는 동아리 공식 전화번호를 발신번호로 사용한다.
- 동아리 공식 전화번호는 운영진만 변경할 수 있다.
- 동아리 공식 전화번호를 변경한 경우 변경된 번호가 문자 발송 서비스에 등록되어 있어야 한다.

### 발송 결과

- 문자 발송은 수신자별로 독립적으로 처리한다.
- 일부 수신자에 대한 발송이 실패하더라도 다른 수신자에 대한 발송은 계속 처리할 수 있다.
