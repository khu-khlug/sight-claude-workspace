# 서비스 정책

사용자에게 보여지는 UI/UX 관련 정책을 정의합니다.

---

## 1. UI 레이아웃

### 콘텐츠 최대 너비

모든 페이지의 주요 콘텐츠는 최대 1024px 너비 내에 표시됩니다.

- 화면 너비 > 1024px: 콘텐츠 중앙 정렬, 좌우 여백
- 화면 너비 ≤ 1024px: 화면 너비에 맞춰 조정

### Navigation Bar

- Blur 효과 적용 (스크롤 시 뒤 콘텐츠가 비쳐 보임)
- 모바일 환경에서도 동일한 기능 제공

---

## 2. 알림 표시

### 읽지 않은 알림 표시

- 알림 아이콘은 Navigation Bar에 위치
- 읽지 않은 알림이 1개 이상: 빨간 점 표시
- 모든 알림을 읽으면: 빨간 점 제거

---

## 3. 일정 표시

### 일정 목록 표시 개수

메인 페이지에서 예정된 일정을 최대 5개까지 표시합니다.

### 일정 구분 표시

일정 유형을 시각적으로 구분하여 표시합니다:
- 개인 일정
- 동아리 일정
- 그룹 일정

---

## 4. 게시판 표시

### 담소(자유게시판) 표시

메인 페이지에서 담소 게시글을 최대 5개까지 표시합니다.

### 표시 정보

각 게시글에 대해 다음 정보를 표시:
- 제목
- 작성자
- 작성일 (상대적 시간 표시, 예: "3일 전")
