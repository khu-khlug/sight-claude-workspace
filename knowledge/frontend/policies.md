# 서비스 정책

사용자에게 보여지는 UI/UX 관련 정책을 정의합니다.

---

## 1. UI 레이아웃

### 콘텐츠 최대 너비

모든 페이지의 주요 콘텐츠는 최대 1024px 너비 내에 표시됩니다.

- 화면 너비 > 1024px: 콘텐츠 중앙 정렬, 좌우 여백
- 화면 너비 ≤ 1024px: 화면 너비에 맞춰 조정

### Navigation Bar

- Blur 효과 적용 (스크롤 시 뒤 콘텐츠가 비쳐 보임)
- 모바일 환경에서도 동일한 기능 제공

---

## 2. 알림

### 알림 카테고리

- **SYSTEM**: 시스템 공지 (운영자 발송)
- **GROUP**: 그룹 관련 알림 (가입 승인, 일정 등)

### 알림 표시

- 알림 아이콘은 Navigation Bar에 위치
- 읽지 않은 알림이 1개 이상: 빨간 점 표시
- 모든 알림을 읽으면: 빨간 점 제거
- 알림 목록은 최신순으로 표시, 페이지네이션 적용 (기본 20개)

### 알림 클릭 동작

- URL이 있는 알림: 해당 URL로 이동
- URL이 없는 알림: 클릭 시 읽음 처리만 수행

### 알림 읽음 처리

- 개별 알림 클릭 시 해당 알림 읽음 처리
- 일괄 읽음 처리 기능 제공 (최대 100개)

---

## 3. 일정 표시

### 일정 목록 표시 개수

메인 페이지에서 예정된 일정을 최대 5개까지 표시합니다.

### 일정 구분 표시

일정 유형을 시각적으로 구분하여 표시합니다:
- 개인 일정
- 동아리 일정
- 그룹 일정

---

## 4. 관리자 회원 목록 페이지 (`/manage/member`)

### 레이아웃

- 목록: 표(table) 형식 — 이름 | 학번 | 학년/학적상태 | 태그 | 상세보기
- 상세: 우측 Drawer (size: sm)

### 정지 회원 표시

- 행 배경: 옅은 주황 (`#fff7e6`)
- 정지 배지: 주황 (`#fa8c16`)
- 서브라인: Pause 아이콘 + `~YYYY/MM/DD` 주황색으로 표시

### 모바일 (768px 이하)

- 표 헤더 숨김, 각 행이 리스트 아이템처럼 표시
- 이름 + [학번 · 학년/학적] + 태그 순으로 세로 나열
- 상세보기는 우측 상단 ChevronRight 아이콘 버튼

---

## 5. 게시판 표시

### 담소(자유게시판) 표시

메인 페이지에서 담소 게시글을 최대 5개까지 표시합니다.

### 표시 정보

각 게시글에 대해 다음 정보를 표시:
- 제목
- 작성자
- 작성일 (상대적 시간 표시, 예: "3일 전")
