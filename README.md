# sight-claude-workspace

사이트 개발에 활용하는 클로드 스킬 및 에이전트를 정의하고 관련 파일을 관리합니다.

## Agents

- **requirements-analyst**: 사용자와 대화하며 요구사항을 명확히 정의하고 기능 명세를 작성합니다.
- **architect**: API 엔드포인트와 DB 스키마를 설계합니다.
- **backend-developer**: 백엔드 코드와 테스트를 작성합니다.
- **frontend-developer**: 프론트엔드 코드를 작성합니다.
- **reviewer**: 프론트엔드와 백엔드 코드를 리뷰하고 개선 방안을 제시합니다.

## Skills

- **requirements-analysis**: 사용자 요구사항을 기능 명세로 변환합니다.
- **api-design**: REST API 엔드포인트 스펙을 정의합니다.
- **db-schema-design**: DB 스키마를 설계합니다.
- **backend-code**: 백엔드 프로덕션 코드를 작성합니다.
- **backend-test**: 백엔드 테스트 코드를 작성합니다.
- **backend-review**: 백엔드 코드 품질을 검토합니다.
- **frontend-code**: 프론트엔드 코드를 작성합니다.
- **frontend-review**: 프론트엔드 코드 품질을 검토합니다.
