# 요구사항 분석

사용자의 요구사항을 API/DB 설계의 입력이 되는 기능 명세로 변환합니다.

## Instructions

### 1. 요구사항 파악
- 사용자가 원하는 기능을 명확히 이해
- 불명확한 부분은 질문으로 확인
- 기존 시스템과의 연관성 파악

### 2. 기능 명세 작성
각 기능에 대해 다음을 정의:
- **기능명**: 간단한 이름
- **설명**: 기능의 목적
- **입력**: 필요한 데이터
- **출력**: 반환되는 결과
- **예외 케이스**: 실패 시나리오

### 3. 출력 형식

```markdown
## [기능명]

### 설명
[기능의 목적과 동작 설명]

### 입력
- [필드명]: [타입] - [설명]

### 출력
- [필드명]: [타입] - [설명]

### 예외 케이스
- [조건]: [에러 메시지]
```

## 역할 범위

- **O**: 요구사항 분석, 기능 명세 작성, 예외 케이스 정의
- **X**: 코드 작성, API 설계, DB 설계 (별도 skill 사용)
