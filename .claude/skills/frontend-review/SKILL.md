# Frontend 코드 리뷰

프론트엔드 코드의 품질과 원칙 준수 여부를 검토합니다.

## 원칙 참조

리뷰 시 다음 문서를 기준으로 검토합니다:
- `knowledge/frontend/principles.md`: 개발 원칙
- `knowledge/frontend/policies.md`: 서비스 정책

## 워크플로우

1. 리뷰 대상 코드 확인
2. 원칙 문서 참조
3. 체크리스트 기준으로 검토
4. 피드백 작성 (파일:라인 형식)

## 체크리스트

### 로직/UI 분리
- [ ] 컴포넌트에 비즈니스 로직이 직접 작성되어 있지 않은가?
- [ ] API 호출이 hooks로 분리되어 있는가?
- [ ] 상태 관리 로직이 적절히 분리되어 있는가?

### 컴포넌트 품질
- [ ] 컴포넌트가 재사용 가능한 단위로 분리되어 있는가?
- [ ] props 타입이 명확히 정의되어 있는가?
- [ ] 불필요한 리렌더링이 발생하지 않는가?

### 타입 안전성
- [ ] any 타입 사용을 피하고 있는가?
- [ ] 적절한 타입/인터페이스가 정의되어 있는가?

### 기타
- [ ] TanStack Query를 적절히 활용하고 있는가?
- [ ] Chakra UI 컴포넌트를 일관성 있게 사용하고 있는가?
- [ ] 서비스 정책(frontend/policies.md)을 준수하고 있는가?

## 출력 형식

```markdown
## 리뷰 결과

### 잘된 점
- [내용]

### 개선 필요
- **[파일:라인]** [문제점] - [개선 방안]

### 권장 사항
- [내용]
```

## 역할 범위

- **O**: 코드 검토, 문제점 지적, 개선 방안 제시
- **X**: 코드 직접 수정 (frontend-code 사용)
