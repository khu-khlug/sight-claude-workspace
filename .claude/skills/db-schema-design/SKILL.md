# DB 스키마 설계

테이블/컬럼/관계를 JPA Entity 관점에서 설계합니다. 설계만 하고 코드는 작성하지 않습니다.

## Instructions

### 1. 테이블 설계
각 테이블에 대해 정의:
- 테이블명 (snake_case)
- 컬럼 목록
- 기본키/외래키
- 인덱스

### 2. 컬럼 정의
각 컬럼에 대해:
- 컬럼명 (snake_case)
- 타입 (MySQL 기준)
- nullable 여부
- 기본값

### 3. 관계 정의
- 1:1, 1:N, N:M 관계 명시
- JPA 어노테이션 관점에서 설명

### 4. 출력 형식

```markdown
## [테이블명]

### 컬럼
| 컬럼명 | 타입 | nullable | 설명 |
|--------|------|----------|------|
| id | BIGINT | NO | PK |

### 관계
- [관계 설명]

### 인덱스
- [인덱스 설명]
```

## 역할 범위

- **O**: 테이블 구조 설계, 관계 정의, 인덱스 설계
- **X**: Entity 코드 작성 (별도 skill 사용)
