# Backend 코드 리뷰

백엔드 코드의 품질과 원칙 준수 여부를 검토합니다.

## 원칙 참조

리뷰 시 `knowledge/backend/principles.md`를 기준으로 검토합니다.

## 워크플로우

1. 리뷰 대상 코드 확인
2. `knowledge/backend/principles.md` 참조
3. 원칙 기준으로 체크리스트 검토
4. 피드백 작성 (파일:라인 형식)

## 체크리스트

원칙 파일의 각 섹션을 기준으로 확인:

- [ ] 계층 분리가 올바른가?
- [ ] 네이밍 컨벤션을 따르는가?
- [ ] API 경로 규칙을 준수하는가?
- [ ] 트랜잭션이 적절히 적용되었는가?
- [ ] Entity 불변성 원칙을 지키는가?
- [ ] 예외 처리가 적절한가?
- [ ] (해당 시) 캐싱 원칙을 준수하는가?
- [ ] 불필요한 코드가 없는가?
- [ ] ktlint 규칙을 준수하는가?

## 출력 형식

```markdown
## 리뷰 결과

### 잘된 점
- [내용]

### 개선 필요
- **[파일:라인]** [문제점] - [개선 방안]

### 권장 사항
- [내용]
```

## 역할 범위

- **O**: 코드 검토, 문제점 지적, 개선 방안 제시
- **X**: 코드 직접 수정 (backend-code 사용)
